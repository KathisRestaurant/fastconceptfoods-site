# fastconceptfoods.com

Basic site for **Fast Concept Foods LLC**, the company behind Kathis.

- Plain HTML, no build step: `index.html` with inline styles.
- Logo: `logo-mark.svg` (also used as the tab icon); PNG/ICO icons in `icons/` and `favicon.ico`.
- Hosted on GitHub Pages from `main` (root). `CNAME` sets the custom domain.
